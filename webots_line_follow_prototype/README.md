# Webots 智能车环境原型

这是一个可丢弃的 Webots 环境，用来确认四轮麦克纳姆底盘、黑线赛道和车载相机能够在同一个世界中正常工作。

## 启动

在此目录运行：

    .\run_webots.ps1

Webots 会以快速模式打开；控制器按20 Hz节拍运行，同时在 `http://localhost:9092` 启动现有视觉调试 WebUI。网页中的原图、二值 ROI、拟合线和控制状态均来自 Webots 虚拟相机与现有 `LineDetector`。

## 已完成的环境部分

- 使用约 0.30×0.30×0.15 m、总质量 1.00 kg 的四轮麦克纳姆智能车原型，不再使用30 kg工业底盘。
- 暂按80 mm轮径建模；轮径是待实测替换的假设值。
- 轮子外观、左右滚子方向以及 `InteriorWheelMat` / `ExteriorWheelMat` 各向异性接触参数复用官方 Fabtino 资产。
- 世界坐标系改为官方模型使用的 ENU（Z 轴向上）。
- 复杂赛道按正式地图的相对拓扑搭建为唯一闭环：底部起点、左侧多边形急弯、上方连续弯、固定环岛路线、右下锯齿路段、底部返回。当前只保留约30 mm宽黑线，不含标志、红绿灯、施工桶或坡道；PDF没有标尺，因此场景尺寸是仿真比例而非官方实测尺寸。
- 通过 `bodySlot` 在车头顶部安装 640×480 前视相机，朝正前方并下俯约 8°，模拟实车观察前方黑线和交通标志的视角。
- 相机更新周期为 32 ms；暂用 90° 水平视场角，等待实车标定后替换。
- 控制器直接导入仓库根目录 `core/line_follower.py` 中的 `LineFollower` / `LineDetector`，没有复制检测或控制算法。
- Webots 适配层只完成 BGRA→BGR 图像转换，以及 `(mm/s, mm/s, mrad/s)`→四轮麦轮速度转换。
- 复用现有 `DebugWebServer` 在 `localhost:9092` 展示虚拟相机和黑线结果。网页可在1–300 mm/s范围内启动/停用虚拟底盘；其他运行参数暂时只读，急停会锁定四轮输出为零。
- 四轮运动学接口采用 `(vx, vy, omega)`，与实车 `(x, y, z)` 命令语义对应。

## 当前边界

当前只接入纯循迹 `LineFollower`，尚未接入 YOLO 和交通标志决策。普通弯、急弯、锯齿和环岛均使用同一套有序中心线、前视曲率与连续控制，不使用地形专用状态机。Fabtino 的质量、轮径和惯量仍与实车不同，因此仿真暂用于验证视觉和控制逻辑，不能直接给出实车动力学参数。

当前1 kg模型完成10秒闭环回归：200/200帧线路有效，失线计数为0，累计位移约0.85 m；包含起步斜坡，稳态控制命令约95 mm/s。
